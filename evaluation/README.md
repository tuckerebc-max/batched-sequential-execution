# BSE adoption

Batched Sequential Execution is installed in the primary and Personal Codex 2 skill directories from [commit 91392bd](https://github.com/tuckerebc-max/batched-sequential-execution/commit/91392bdf5206c5e7833b04092a5ff1a683e36f75). The coordinator verified that both installations contain the same 137 files. Both seats' standing instructions now call for frequent use on suitable authorized tasks and evaluation after actual use, while preserving existing capacity and publication gates.

Use the [evaluation protocol](EVALUATION.md), [per-run scorecard](TRIAL-TEMPLATE.md), and [shared outcome-record instructions](outcomes/README.md). The first three suitable uses are pilots. Every third completed use, and after a meaningful revision, prompts a matched comparison when authorization and capacity permit.

Personal Codex 2 independently checked the copied package: CLI help and ten review-gate tests passed; its 137 source files stayed unchanged. [Baseline evidence](BASELINE.json) records the commands and limits. The earlier complete software test matrix passed on GitHub.

No comparative effectiveness trial has yet been completed. Successful software tests do not establish that batching improves the finished work. Evaluation is triggered by use; no recurring primary-account polling job was created.
