# BSE outcome records

This shared directory is the record location for actual BSE uses across both Codex seats. No actual-use or comparative-effectiveness records have been created at setup.

For each suitable authorized use, copy [TRIAL-TEMPLATE.md](../TRIAL-TEMPLATE.md) to a file named `YYYY-MM-DD-<unique-task-or-run-id>.md` here. Record the task's stable ID and maintain only that task's file. Keep any private sources and artifacts in their authorized project; record permitted references and measurements here without duplicating sensitive source content.

Determine the completion count from distinct task/run IDs with completed status in this directory. Count one suitable task once, not each batch or each seat. The first three suitable uses are pilots. Keep blocked and abandoned records visible, but do not count them as completed uses. This readiness check, README, and blank template are not pilots.

At every third completed use and after a meaningful method revision, apply the matched-comparison checkpoint in [EVALUATION.md](../EVALUATION.md). Put the comparison ID, linked run IDs, status, evidence, and any pending reason in the relevant record. Preserve task authorization, publication gates, and the existing account-capacity policy; no timer, primary-account polling job, or automatic expansion of scope is established by this directory.
