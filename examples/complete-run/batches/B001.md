# Source Catalog

This catalog is the only unit that reads all five source files in full.
Every later body section (B002-B006) reads this catalog plus only the
specific source slice its own section needs.

- [S1] sources/peer-program-outcomes.md — a compiled memo covering three
  peer agencies (Meridian Transit, launched March 2023; Cedar Falls Regional
  Transit, launched September 2022; Ashford Regional Transit, a 14-month
  corridor pilot from March 2024) and what each reported for off-peak
  ridership, revenue, cost, and timeline after implementing an off-peak fare
  cap. Feeds: B002 (peer evidence) and, for its phasing/awareness lessons,
  B006 (implementation options).
- [S2] sources/riverton-ridership-data.md — RTA's own FY2026 data: 21.4
  million system-wide boardings, the mechanics of RTA's existing all-day
  cap (in place since 2019), the three-way AM peak/daytime/off-peak
  boardings-and-revenue breakdown, and off-peak seat-occupancy figures
  showing spare capacity. Feeds: B003 (RTA's own ridership and revenue) and,
  by reference rather than restatement, the capacity point B005 needs.
- [S3] sources/farebox-tech-memo.md — an RTA IT/Fare Systems memo explaining
  that RiverPass currently evaluates the all-day cap in a nightly batch job,
  not in real time, and scoping two paths to a time-of-day cap: a
  $410,000/9-month real-time option and an $85,000/3-month interim
  batch-credit option, each with a different rider-experience tradeoff.
  Feeds: B005 (operational and technical feasibility).
- [S4] sources/equity-analysis-notes.md — the Equity & Access office's
  analysis showing RTA's 41,000 reduced-fare enrollees account for 33% of
  off-peak boardings against 19% system-wide, why the current all-day cap
  structurally underserves an off-peak-only rider, the four corridors where
  enrollment concentrates, and the office's own caution about riders
  eligible for but not enrolled in reduced fare. Feeds: B004 (equity and
  access implications).
- [S5] sources/stakeholder-interview-notes.md — interview notes with the
  driver union (advance-notice requirement for any fare change), RTA Access
  paratransit (a boundary question about whether a fixed-route cap implies
  anything for Access fares), and RTA Finance (a preference for phased,
  revenue-tested rollout over a single system-wide cutover). Feeds: B006
  (implementation options and tradeoffs).
