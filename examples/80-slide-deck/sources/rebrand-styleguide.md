# Rebrand Style Guide — Voltane Robotics -> Meridian Grid Robotics (fictional)

Effective for all investor- and customer-facing materials starting with the
Q3 2026 reporting cycle, following the merger close announced August 2026.

## Naming

- Company name: "Voltane Robotics" -> "Meridian Grid Robotics" everywhere,
  including in slide footers, headers, and speaker notes that are shown on
  screen (not presenter-only notes, which are out of scope for this edit
  pass).
- Stock ticker: "VOLT" -> "MRDN" everywhere a ticker is shown.
- Product line: "battery pack" -> "energy module" (the flagship hardware
  product's approved name going forward; "battery pack" was the pre-merger
  name and reads as a downgrade to the new positioning).
- Do not rename "Meridian Grid Robotics" to any shortened form ("Meridian,"
  "MGR") in this deck; the full name is used on every slide that names the
  company, per the board's request for this filing cycle specifically.

## Visual identity

- Primary brand color: #1B3A5C (deep slate blue), replacing the prior
  #2F7A3C (forest green) on all chart series, section dividers, and callout
  boxes.
- Accent color for growth/positive figures: #E8A33D (amber), replacing the
  prior #66C266 (light green).
- Logo lockup: horizontal wordmark only in this deck; no icon-only mark on
  slides (icon-only mark is reserved for the app and internal tools).

## Financial figures

- All financial figures on customer- and investor-facing slides must reflect
  Q3 2026 actuals (sources/q3-2026-actuals.md), not the Q3 2025 figures used
  in the prior version of this deck, and must carry an [S#] source tag.
- Any slide comparing this quarter to a prior quarter must use the label
  "Q3 2026 vs. Q3 2025" exactly (not "YoY" alone, not "this year vs. last
  year") for consistency with the earnings-call script.
